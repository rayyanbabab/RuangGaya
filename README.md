## 📖 Tentang RuangGaya

**RuangGaya** adalah aplikasi web studio photobooth virtual mandiri yang menghadirkan pengalaman berfoto ala studio Korea (seperti *Life4Cuts*, *Haru Film*, *Photism*, dan *Jepreto*) langsung dari peramban tanpa memerlukan instalasi aplikasi tambahan atau perangkat keras mahal.

Cukup menggunakan kamera laptop atau ponsel pintar, pengguna dapat memilih berbagai macam tata letak cetak (*strip*), memasang filter pelacak wajah berbasis kecerdasan buatan (**Google MediaPipe Vision**), memilih latar bingkai yang sedang tren (mulai dari Sal Priadi Newspaper, Batik Nusantara, Y2K Cyber, Disney/Pixar, hingga meme populer), menghias foto dengan stiker *drag-and-drop*, dan langsung mengunduh hasilnya dalam bentuk **foto cetak beresolusi tinggi (PNG/JPEG)**, **animasi bergerak GIF**, atau **QR Code sharing** untuk ponsel.

## ✨ Fitur Utama

### 1. Pilihan Grid & Template Photostrip
Mendukung 9 variasi komposisi tata letak foto fleksibel:
* **1×1 Polaroid**: Format polaroid 1-shot klasik dengan area tanda tangan di bawah foto.
* **2×1 Duo Strip**: 2 foto vertikal minimalis yang bersih dan tajam.
* **3×1 Classic Strip**: Format 3 foto vertikal ala photostrip bioskop vintage.
* **4×1 Korean Strip**: Format 4-strip vertikal ikonik khas studio Korea (Life4Cuts style).
* **1×2 Wide Duo**: Lanskap 2 foto berjajar ke samping.
* **2×2 Square Grid**: Grid kotak 4 foto seimbang yang populer di media sosial.
* **2×3 Story Grid**: 6 foto vertikal berderet bergaya Instagram Story.
* **3×2 Wide Grid**: Format lanskap sinematik 6 foto.
* **4×2 Party Board**: Format mega-board 8 foto untuk keseruan bersama geng dan teman nongkrong.

Menggunakan integrasi `@mediapipe/tasks-vision` yang mendeteksi 478 titik koordinat landmark wajah secara *real-time* di 60 FPS:
* 🐱 **Cat & Dog**: Telinga, kumis kucing berkedip, dan telinga anjing bergerak gemas.
* 👑 **Crown & Fairytale**: Mahkota emas berpermata dan mahkota bunga sakura (*cherry blossom*).
* 💄 **Beauty & Glow**: Penghalusan tekstur kulit alami (*skin smoothing*), efek pencerah rona wajah, dan blush pipi.
* 🦋 **Butterfly & Wings**: Sayap kupu-kupu fantasi bercahaya di pelipis wajah.
* 😎 **Thug Life & Cyber Visor**: Kacamata hitam pixel 8-bit retro dan kacamata visor neon sci-fi.
* 😈 **Devil & Angel**: Tanduk neon merah membara dan halo malaikat emas melayang.
* 🥸 **Gentleman**: Kumis klasik vintage dan kacamata bulat.
* 🌸 **Daisy Cheek & Heart Blush**: Sentuhan blush love merona dan taburan bunga daisy.

### 5. Stiker & Layer Dekorasi Interaktif (React-Moveable)
* **Drag, Rotate, Scale**: Pindahkan, putar 360°, dan ubah ukuran stiker bebas di atas canvas photostrip.
* **Perpustakaan Stiker Lengkap**: Aksesoris kacamata, pita coquette, stempel photobooth Korea (*Besties*, *Photo Dump*, *Cutie*), emoji, doodle, dan elemen meme.
* **Layer Control**: Hapus atau susun urutan stiker dengan mudah.

### 6. Kustomisasi Tipografi & Teks Bebas
* Tambahkan teks caption, tanggal momen, atau nama acara di bagian atas atau bawah photostrip.
* Pilihan jenis font modern dari Google Fonts:
  * **Friendly**: *Nunito*
  * **Elegant**: *Playfair Display*
  * **Playful**: *Pacifico*
  * **Retro**: *Courier Prime*
  * **Modern**: *Outfit*
  * **Handwriting**: *Dancing Script*
* Pengaturan ukuran teks, warna font kontras otomatis, dan perataan simetris.

### 7. Studio Kontrol & Shutter Audio Cerdas
* **Mirror Flip Camera**: Kemudahan melihat pantulan kamera depan seperti cermin asli.
* **Countdown Timer Fleksibel**: Pilihan hitungan mundur 3 detik, 5 detik, atau 10 detik dengan suara bip audio interaktif.
* **Audio Shutter SFX & Efek Flash**: Efek kilatan cahaya shutter realistis saat pengambilan gambar.
* **Auto-Shoot Mode**: Ambil seluruh slot foto secara berurutan secara otomatis tanpa perlu menekan tombol berulang kali.
* **Slot Retake Satuan**: Jika ada salah satu pose yang kurang pas, Anda dapat mengulang pengambilan gambar pada slot tersebut saja tanpa harus mengulang seluruh rangkaian foto.

### 8. Multi-Format Export: HD Image, Animasi GIF & QR Code
* **HD Photo Strip (PNG / JPEG)**: Render kanvas beresolusi tinggi (1200×900 px per foto) yang tajam untuk dicetak fisik ke kertas foto.
* **Animated GIF Export (`gifshot`)**: Menyatukan semua pose menjadi animasi gambar bergerak mini berulang yang siap diunggah ke Instagram Story atau TikTok.
* **QR Code Instant Mobile Download (`qrcode`)**: Pindai QR Code di layar menggunakan kamera smartphone untuk langsung membuka dan menyimpan foto ke galeri ponsel.
* **Edit Studio**: Masuk ke studio pengeditan setelah berfoto untuk mengganti template bingkai, mengganti filter warna, atau menambahkan stiker sebelum mengunduh.

## 🛠️ Tech Stack & Library Pendukung

| Kategori | Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Framework Utama** | Next.js 15 (App Router) | Server-side rendering, routing modern, dan optimasi bundle |
| **UI Library** | React 19 + TypeScript | Komponen antarmuka reaktif dengan type-safety ketat |
| **AI Computer Vision** | `@mediapipe/tasks-vision` | Model Face Landmarker Google untuk pelacakan 478 titik wajah |
| **Canvas Manipulation** | HTML5 Canvas 2D + `html2canvas` | Komposisi multi-layer, frame clipping, dan rendering strip resolusi tinggi |
| **Interactive UI** | `react-moveable` | Mesin interaksi drag, resize, rotate stiker & dekorasi |
| **GIF Synthesizer** | `gifshot` | Generator animasi GIF langsung di sisi client (browser) |
| **QR Code Generator** | `qrcode` | Pembuatan QR Code dinamis untuk transfer instan ke mobile |
| **Styling** | Vanilla CSS Modules | Desain responsif berkinerja tinggi tanpa dependensi framework CSS berat |
| **Deployment Target** | Vercel | Platform cloud hosting teroptimasi untuk Next.js |

## 🚀 Panduan Instalasi & Menjalankan Lokal

### Prasyarat
* [Node.js](https://nodejs.org/) versi 18.18 atau lebih baru (Disarankan Node.js 20 LTS atau 22 LTS).
* Git terpasang pada komputer Anda.
* Peramban modern (Chrome, Edge, Safari, Firefox) dengan izin akses webcam.

### Langkah-langkah

1. **Clone Repository ini:**
   ```bash
   git clone https://github.com/rayyanbabab/RuangGaya.git
   cd RuangGaya
   ```

2. **Instalasi Semua Dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Aplikasi dalam Mode Pengembangan:**
   ```bash
   npm run dev
   ```

4. **Buka Aplikasi di Peramban:**
   Buka peramban Anda dan kunjungi:
   ```
   http://localhost:3000
   ```
   *(Pastikan memberikan izin akses kamera (Allow Webcam) saat diminta oleh peramban).*

5. **Build dan Jalankan untuk Mode Produksi:**
   ```bash
   npm run build
   npm run start
   ```

## 🌐 Panduan Deployment ke Vercel

RuangGaya telah dioptimasi secara native untuk dideploy di platform serverless **Vercel**:

1. Masuk ke [Vercel Dashboard](https://vercel.com/) dan klik **Add New Project**.
2. Hubungkan repository GitHub Anda: `rayyanbabab/RuangGaya`.
3. Vercel akan secara otomatis mendeteksi framework **Next.js**.
4. Biarkan konfigurasi build default:
   * **Framework Preset:** Next.js
   * **Build Command:** `next build`
   * **Output Directory:** `.next`
5. Klik **Deploy**. Dalam hitungan detik, photobooth online Anda sudah aktif dan dapat diakses dari seluruh dunia.
